# Joshua Bettles personal website refresh

This is a first-pass redesign of `joshua-bettles.github.io`, using the dark charcoal, purple accent, restrained typography, sticky navigation and responsive layout approach from the supplied PiNE 2027 website.

## Files changed
- `index.html` — refreshed homepage, research focus, fellowships and contact details
- `publications.html` — clearer publication cards and PDF links
- `blog.html` — redesigned blog listing; article destinations are intentionally marked as coming soon because separate article pages were not included in the supplied site
- `cv.html` — CV timeline and PDF link
- `assets/personal.css` — new shared responsive styling

The original image and PDF assets have been preserved. Existing unused Mobirise assets are also retained so this is a safe, incremental first pass. No build step is required; publish the contents of this folder to GitHub Pages.

Please review dates, titles and wording before publishing. The site content is based on the supplied archive.
