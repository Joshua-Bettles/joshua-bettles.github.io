# Joshua Bettles Website — Red Accent Edition

## Structure
- `index.html` — root redirect for GitHub Pages
- `home/` — homepage with its own stylesheet and assets
- `publications/` — publications page with its own stylesheet and papers
- `blog/` — blog page with its own stylesheet and images
- `cv/` — CV page with its own stylesheet and CV PDF

Each page is self-contained in its own folder. The CSS and assets are intentionally local to each page so sections can be changed independently.

## Deploy
Upload the contents of this folder to the root of the `joshua-bettles.github.io` repository. GitHub Pages will serve the root redirect, which forwards visitors to `home/index.html`.
